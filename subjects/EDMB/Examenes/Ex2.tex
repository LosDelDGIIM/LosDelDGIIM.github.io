    \begin{ejercicio}
        Sea $u_t + t u_x = 0$, con $u : \left[0, T \right[ \times \R \to \R$. Demuestra que $u$ se conserva a lo largo de las trayectorias características. \\

        Obtenemos en primer lugar las trayectorias características. En este caso, $\omega(t,x) = t$. El sistema característico asociado al modelo de transporte es 
        \begin{equation*}
            \begin{cases}
                \dfrac{\partial X}{\partial t}(t;s,x)
                =\omega(t,X(t;s,x)) = t\\[6pt]
                X(s;s,x)=x
            \end{cases}\quad s \in \left[0, T \right[
        \end{equation*}
        %La primera ecuación se resuelve por variables separadas (escribimos $X(t) \equiv X(t;s,x)$):
        %$$\dfrac{dX}{dt} = X' = t \Longrightarrow dX = t dt \Longrightarrow X(t) = \dfrac{t^2}{2} + C \quad C \in \R$$
        %e imponiendo la condición inicial $X(s) = x$:
        %$$\dfrac{s^2}{2} + C = X(s) = x \Longrightarrow C = x - \dfrac{s^2}{2}$$
        %luego
        %$$X(t;s,x) = \dfrac{t^2}{2} + x - \dfrac{s^2}{2} = x + \dfrac{t^2 - s^2}{2}$$
        Para ver que $u$ se conserva a lo largo de las trayectorias características, primeramente hay ver que 
        $$\dfrac{d}{dt}u(t,X(t;s,x)) = 0$$
        Aplicando la regla de la cadena:
        $$
        \dfrac{d}{dt}u(t,X(t;s,x)) =u_t(t,X(t;s,x)) + u_x(t,X(t;s,x))\frac{\partial X}{\partial t}(t;s,x)$$
        Usando que $u$ verifica la ecuación del enunciado, sustituyendo $x$ por $X(t;s,x)$ se tiene que
        $$u_t(t,X(t;s,x))+t\,u_x(t,X(t;s,x))=0$$
        y como 
        $$\dfrac{\partial X}{\partial t}(t;s,x) = \omega(t,X(t;s,x)) = t$$
        por ser una trayectoria característica, nos queda lo que queremos probar:
        $$\dfrac{d}{dt}u(t,X(t;s,x)) = 0$$
        Deducimos entonces que la función $t\mapsto u(t,X(t;s,x))$ es constante, luego
        $$
        u(t,X(t;s,x))=u(s,X(s;s,x)).
        $$

        Y como $X(s;s,x)=x$, nuevamente por ser trayectoria característica, llegamos al resultado
        $$
        \boxed{u(t,X(t;s,x))=u(s,x) \quad \forall t,s \in \left[0, T\right[ \quad \forall x \in \R}
        $$

        Así, el valor de $u$ permanece constante a lo largo de cada trayectoria característica (toma el valor del instante inicial $s$). Por tanto, $u$ se conserva a lo largo de dichas trayectorias, como queríamos demostrar.
    \end{ejercicio}

    \begin{ejercicio}
        Resolver 
        \begin{equation}\label{eq:ec1}
            \begin{cases}
                u_t + e^x u_x = 0 \\
                u(0,x) = x
            \end{cases}
        \end{equation}
        Sabemos por los dos teoremas vistos en clase correspondientes, que tanto la teoría clásica como la teoría débil nos proporcionan existencia y unicidad de soluciones de \eqref{eq:ec1}, y, en caso de verificarse todas las hipótesis, dicha solución única es
        $$u(t,x) = u_0(X(0;t,x))$$
        Sin embargo, en este problema concreto, el teorema para las soluciones clásicas no nos sirve, ya que (H3) no se verifica, puesto que $\omega(t,x) = |e^x|$ no tiene crecimiento sublineal.
        Tampoco podemos aplicar el teorema para las soluciones débiles, puesto que:
        $$\di_x(\omega) = \dfrac{\partial \omega}{\partial x}(t,x) = e^x \neq 0 \quad \forall x \in \R$$
        %Veamos primero las hipótesis para obtener la solución por la vía clásica. En este caso, $\omega(t,x) = e^x$, y $u_0(x) = x$. Primero vemos que se verifican (H1)-(H4):
        %\begin{itemize}
        %    \item[(H1)] Se cumple porque $\omega(t,x)$ es exponencial en la variable $x$, y no depende de $t$. En particular $\omega$ es continua en los dos argumentos.
        %    \item[(H2)] $\omega$ es localmente Lipschitz respecto de $x$, ya que $\omega \in C^1(\left[0,T \right[ \times \R)$, luego $C^1_x(\left[0,T \right[ \times \R)$, y sabemos por un resultado visto en Ecuaciones Diferenciales II que es l.l. resp. de $x$.
        %    Otra forma sería verlo por definición aplicando el Teorema del Valor Medio en un entorno de la forma $I \times J$, con $I = \left]t_0-\delta, t_0 + \delta \right[ \cap \left[0, T\right[$ y $J = \left]x_0-r, x_0 + r \right[$, fijados $(t_0, x_0) \in \left[0, T\right[ \times \R$ y ciertos valores de $\delta, r > 0$.
        %    Así, para cualesquiera $(t,x),(t,y) \in I \times J$, por dicho teorema tendríamos que:
        %    $$|\omega(t,x)-\omega(t,y)| =|e^x-e^y| = e^\xi|x-y| \leq e^{x_0+r}|x-y|$$
        %    para cierto $\xi$ entre $x$ e $y$. Tomando $L = e^{x_0 + r} > 0$ se tiene la condición l.l. resp. de $x$.
        %    \item[(H3)] Como $\omega(t,x) = -tx$, en particular, $$|\omega(t,x)| \leq |t||x| + 0 < T|x| + 0 = A|x| + B$$
        %    para todo $(t,x) \in \left[0, T \right[ \times \R$, por lo que el crecimiento es sublineal.
        %    \item[(H4)] La aplicación \Func{\dfrac{\partial \omega}{\partial x}}{\left[0, T \right[ \times \R}{\R}{(t,x)}{\dfrac{\partial \omega}{\partial x}(t,x) = -t} es polinómica en $t$, luego continua.
        %\end{itemize}
        %Como además es claro que $u_0 \in C^1(\R)$, el teorema mencionado al principio nos dice que el PVI \eqref{eq:ec1} admite una única solución, 
        %$u \in C^1(\left[0, T \right[ \times \R)$, que viene dada por 
        %$$u(t,x) = u_0(X(0;t,x))$$ 
        Aún así, tratamos de buscar una solución a \eqref{eq:ec1} que tenga la misma forma que la que nos proporcionan ambos teoremas, y luego verificar que sea solución. Así, buscamos una solución de la forma que hemos dicho al principio.
        En este caso, $u_0(x) = x$. El sistema característico asociado a \eqref{eq:ec1} es 
        \begin{equation*}
            \begin{cases}
                \dfrac{\partial X}{\partial t}(t;s,x)
                =\omega(t,X(t;s,x)) = e^{X(t;s,x)}\\[6pt]
                X(s;s,x)=x
            \end{cases}\quad s \in \left[0, T \right[
        \end{equation*}
        La primera ecuación se resuelve por variables separadas (escribimos $X(t) \equiv X(t;s,x)$):
        $$\dfrac{dX}{dt} = X' = e^X \Longrightarrow e^{-X}dX = \dfrac{dX}{e^X} = dt \Longrightarrow -e^{-X(t)} = t + C \Longrightarrow$$
        $$e^{-X(t)} = -t - C \Longrightarrow -X(t) = \ln(-t-C) \Longrightarrow X(t) = -\ln(-t-C) \quad C \in \R$$
        e imponiendo la condición inicial $X(s) = x$:
        $$-\ln(-s-C) = X(s) = x \Longrightarrow \ln(-s-C) = -x \Longrightarrow -s - C = e^{-x} \Longrightarrow C = - s - e^{-x}$$
        luego
        $$X(t;s,x) = -\ln(-t-(- s - e^{-x})) = - \ln(e^{-x} + s - t)$$
        Vemos que esta expresión solo está definida cuando el argumento del logaritmo es positivo, es decir,
        $$e^{-x}+s-t>0 \iff t<s+e^{-x}$$
        Esto significa que las trayectorias características no están necesariamente definidas para todo $t\in \left[0,T\right[$, lo cual está relacionado con que no se cumpla (H3).
        Como $X(0;t,x) = - \ln(e^{-x} + t)$, la ``solución'' a la que llegamos de \eqref{eq:ec1} es
        $$\boxed{u(t,x) = u_0(X(0;t,x)) = X(0;t,x) = - \ln(e^{-x} + t)}$$
        Veamos si en efecto es solución. Calculamos:
        $$u_t(t,x)=-\frac{1}{e^{-x}+t}$$
        y
        $$u_x(t,x)=\frac{e^{-x}}{e^{-x}+t}$$
        Luego,
        $$u_t+e^xu_x =-\frac{1}{e^{-x}+t} + \frac{e^xe^{-x}}{e^{-x}+t} =0$$
        Además,
        $$u(0,x)=-\ln(e^{-x})=x$$
        Así, hemos resuelto \eqref{eq:ec1}, como se pedía.
    \end{ejercicio}

    \begin{ejercicio}
        Calcular las ondas de choque y rarefacción del problema de Riemann
        $$u_0(x) = \begin{cases}
            -1 \quad& x<0 \\
             1 \quad& x>0
        \end{cases}$$
        Sabemos por teoría que las soluciones de la ecuación de Burgers (las trayectorias características) son rectas,
        donde la pendiente la determina la condición inicial $u(0,x) = u_0(x)$, o sea, $X(t;0,x) = x + u_0(x)t$. Así pues:
        $$X(t;0,x) = \begin{cases}
            x - t \quad& x < 0 \\
            x + t \quad& x > 0
        \end{cases}$$
        Una solución débil del problema de Riemann (que es el problema de Burgers con un dato inicial con salto) que conocemos es la siguiente:
        $$u_1(t,x) = \begin{cases}
            u^{-} \quad& x < \lm t \\
            u^{+} \quad& x > \lm t
        \end{cases}$$
        donde $u^{-} = -1$ y $u^{+} = 1$ se obtienen del dato inicial. Se ha visto en teoría que el único valor de $\lm$ para 
        que $u$ sea solución (débil) es, aplicando la condición de salto de Rankine-Hugoniot:
        $$\lm = \dfrac{1}{2}(u^{-} + u^{+}) = \dfrac{1}{2}(-1+1) = 0$$
        por lo que ya tenemos una solución del problema de Riemann: 
        $$\boxed{u_1(t,x) = \begin{cases}
            -1 \quad& x < 0 \\
            1 \quad& x > 0
        \end{cases}}$$
        Como además el dato inicial $u_0(x)$ es creciente, sabemos por teoría que tendremos también ondas de rarefacción. Las características ya
        las hemos obtenido:
        $$X(t;0,x) = \begin{cases}
            x - t \quad& x < 0 \\
            x + t \quad& x > 0
        \end{cases}$$
        Obtenemos las rectas que delimitan la región de las ondas de rarefacción haciendo $x \to 0$ en ambos lados, y vemos que:
        $$\lim\limits_{x \to 0^{-}}X(t;0,x) = -t$$
        $$\lim\limits_{x \to 0^{+}}X(t;0,x) = t$$
        Así, las fronteras de la región de rarefacción son $x = -t$ y $x=t$. Las tres regiones que tenemos son $x < -t$, $-t \leq x \leq t$ y $x > t$.
        Según se ha visto en teoría, las ondas de rarefacción pueden construirse como la solución autosemejante o autosimilar $u(t,x) = x/t$,
        y teniendo en cuenta los límites ya obtenidos de la región de rarefacción, una segunda solución (en este caso continua para $t > 0$)
        del problema de este ejercicio es:
        $$\boxed{u_2(t,x) = \begin{cases}
            -1 \quad& x < -t \\
            \dfrac{x}{t} \quad& -t \leq x \leq t \quad t > 0\\
            1 \quad& x > t \\
        \end{cases}}$$
        En $t=0$ tenemos la condición inicial $u(0,x) = u_0(x)$.
    \end{ejercicio}
