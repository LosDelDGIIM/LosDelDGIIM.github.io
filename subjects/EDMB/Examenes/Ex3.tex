    \begin{ejercicio}
        Resuelve el problema
        \begin{equation}\label{eq:ec1}
            \begin{cases}
                u_t + c^2u_x = 0 \\
                u(0,x) = \sen(x)
            \end{cases}
        \end{equation}
        Sabemos por los dos teoremas vistos en clase correspondientes, que tanto la teoría clásica como la teoría débil nos proporcionan existencia y unicidad de soluciones de \eqref{eq:ec1}, y, en caso de verificarse todas las hipótesis, dicha solución única es
        $$u(t,x) = u_0(X(0;t,x))$$
        Dado que no se especifica si usar la vía clásica o la vía débil para resolver el problema, y que la solución obtenida será la misma (en caso de que se pueda ir por esa vía), optamos por la vía clásica. En este caso, $\omega(t,x) = c^2$, para cierto $c \in \R$, y $u_0(x) = \sen(x)$. Primero vemos que se verifican (H1)-(H4):
        \begin{itemize}
            \item[(H1)] Se cumple porque $\omega(t,x)$ es constante, en particular $\omega$ es continua en los dos argumentos.
            \item[(H2)] $\omega$ es localmente Lipschitz respecto de $x$, ya que $\omega \in C^1(\left[0,T \right[ \times \R)$, luego $C^1_x(\left[0,T \right[ \times \R)$, y sabemos por un resultado visto en Ecuaciones Diferenciales II que es l.l. resp. de $x$.
            Otra forma sería verlo por definición directamente: para cualesquiera $x,y \in \R$ se tiene que
            $$|\omega(t,x) - \omega(t,y)| = |c^2-c^2| = 0 \leq L|x-y|$$
            Se cumple para todo $L>0$. De hecho, es globalmente Lipschitz.
            para cualquier entorno de $(t,x)$ y $(t,y)$ de la forma $I \times \R$, con $I \subseteq \left[0,T \right[$ un intervalo acotado. 
            \item[(H3)] Como $\omega(t,x) = c^2$, en particular, $$|\omega(t,x)| \leq 0|x| + c^2 = A|x| + B$$
            para todo $(t,x) \in \left[0, T \right[ \times \R$, por lo que el crecimiento es sublineal.
            \item[(H4)] La aplicación \Func{\dfrac{\partial \omega}{\partial x}}{\left[0, T \right[ \times \R}{\R}{(t,x)}{\dfrac{\partial \omega}{\partial x}(t,x) = 0} es constante, luego continua.
        \end{itemize}
        Como además es claro que $u_0 \in C^1(\R)$, el teorema mencionado al principio nos dice que el PVI \eqref{eq:ec1} admite una única solución, 
        $u \in C^1(\left[0, T \right[ \times \R)$, que viene dada por 
        $$u(t,x) = u_0(X(0;t,x))$$ 
        El sistema característico asociado a \eqref{eq:ec1} es 
        \begin{equation*}
            \begin{cases}
                \dfrac{\partial X}{\partial t}(t;s,x)
                =\omega(t,X(t;s,x)) = c^2\\[6pt]
                X(s;s,x)=x
            \end{cases}\quad s \in \left[0, T \right[
        \end{equation*}
        La primera ecuación se resuelve por variables separadas (escribimos $X(t) \equiv X(t;s,x)$):
        $$\dfrac{dX}{dt} = X' = c^2 \Longrightarrow dX = c^2 dt \Longrightarrow X(t) = c^2 t + C \quad C \in \R$$
        e imponiendo la condición inicial $X(s) = x$:
        $$c^2 s + C = X(s) = x \Longrightarrow C = x - c^2 s$$
        luego
        $$X(t;s,x) = c^2 t + x - c^2 s = x + c^2(t-s)$$
        y como $X(0;t,x) = x - c^2t$, la única solución (clásica) de \eqref{eq:ec1} es
        $$\boxed{u(t,x) = u_0(X(0;t,x)) = \sen(x - c^2t)}$$
    \end{ejercicio}

    \begin{ejercicio}
        ¿El problema anterior tiene solución débil para $u_0(x)$?
        $$u_0(x) = \begin{cases}
            0 \quad& x<0 \\
            1 \quad& x>0
        \end{cases}$$
        Si es así, define su solución débil. \\

        Para ver si tiene solución débil, veamos si se verifican las hipótesis del teorema de existencia y unicidad de soluciones débiles de \eqref{eq:ec1}. 
        Ya hemos visto en el ejercicio anterior que se cumplen (H1)-(H4), y además $\text{div}_x(\omega) = 0$, ya que $\omega$ es constante. Como $u_0$ es en particular $L_{loc}^1(\R)$ (lo vemos cuando
        se defina el concepto de solución débil), por dicho teorema sabemos que existe una única solución débil de \eqref{eq:ec1}, y que esta tiene la misma forma que la hemos obtenido antes, pero ahora el dato inicial $u_0(x)$ es distinto, por lo que:
        $$u_0(X(0;t,x)) = 
        \begin{cases}
            0 \quad& X(0;t,x) < 0 \\
            1 \quad& X(0;t,x) > 0
        \end{cases} = \begin{cases}
            0 \quad& x - c^2t < 0 \\
            1 \quad& x - c^2t > 0
        \end{cases} = \begin{cases}
            0 \quad& x < c^2t \\
            1 \quad& x > c^2t
        \end{cases}$$

        Teniendo esto último en cuenta, la solución será
        $$\boxed{u(t,x) = u_0(X(0;t,x)) = \begin{cases}
            0 \quad& x < c^2t \\
            1 \quad& x > c^2t
        \end{cases}}$$

        Vemos que esto nos recuerda a un problema de Riemann, y aplicando la condición de salto de Rankine-Hugoniot al modelo 
        \begin{equation*}
            \begin{cases}
                \dfrac{\partial u}{\partial t} + \dfrac{\partial}{\partial x}(f(u)) = 0 \\
                u(0,x) = u_0(x)
            \end{cases}
        \end{equation*}
        con $f(u) = c^2u$, el valor de $\lm$ visto en teoría es, teniendo en cuenta que $u^{-} = 0$ y $u^{+} = 1$:
        $$\lm = \dfrac{f(u^{+}) - f(u^{-})}{u^{+} - u^{-}} = \dfrac{c^2\cdot1-c^2\cdot0}{1-0} = c^2$$
        Dicho lo anterior, definimos el concepto de solución débil. Primero vemos que $\omega \in L^\infty_{loc}(\left[0, T \right[ \times \R)$ y $u_0 \in L_{loc}^1(\R)$. Lo primero 
        por ser $\omega$ continua, por lo que está acotada en compactos por el Teorema de Weierstrass, y por tanto,
        es integrable en compactos, es decir, localmente integrable. Lo segundo porque $u_0$ está acotada, pues $|u_0(x)| \leq 1$ para todo $x \in \R$, luego $u_0 \in L^{\infty}(\R)$ y $u_0 \in L^1_{loc}(\R)$, ya que toda función acotada es integrable sobre compactos, o sea, localmente integrable. 
        Así, una solución débil de \eqref{eq:ec1} es una función $u \in L^1_{loc}(\left[0, T \right[ \times \R^N)$ que verifica 
        $$- \int_{0}^{T} \int_{\R^N} \left[ \dfrac{\partial \varphi}{\partial t} + (\omega \cdot \nabla_x) \varphi \right] u \,dx\,dt = \int_{\R^N} u_0(x) \varphi(0,x)\,dx$$ 
        para todo $\varphi \in C_c^1(\left[0,T \right[ \times \R^N)$. En nuestro caso, $N=1$, $\omega(t,x) = c^2$ y $u_0(x)$ es el dato inicial de este ejercicio, luego $u$ debe verificar 
        $$-\int_0^T\int_{\R} [\varphi_t+c^2\varphi_x]u\,dx\,dt =\int_{\R}u_0(x)\varphi(0,x)\,dx =\cancelto{0}{\int_{-\infty}^0 0\cdot\varphi(0,x)\,dx} + \int_0^{+\infty}1\cdot\varphi(0,x)\,dx = $$
        $$\int_0^{+\infty}\varphi(0,x)\,dx$$
        para todo $\varphi \in C_c^1(\left[0,T \right[ \times \R)$. Resumidamente, $u$ debe verificar
        $$-\int_0^T\int_{\R} [\varphi_t+c^2\varphi_x]u\,dx\,dt = \int_0^{+\infty}\varphi(0,x)\,dx$$
        para todo $\varphi \in C_c^1(\left[0,T \right[ \times \R)$.
    \end{ejercicio}

    \begin{ejercicio}
        Calcule las ondas de choque de la ecuación de Burgers asociada a
        $$u_0(x) = \begin{cases}
            0 \quad& x<0 \\
            1/2 \quad& 0<x<1 \\
            1 \quad& x>1
        \end{cases}$$
        En primer lugar obtenemos las trayectorias características:
        $$X(t; 0, x) = x + u_0(x) t = \begin{cases}
            x \quad& x < 0 \\
            x + t/2 \quad& 0 < x < 1 \\
            x + t \quad& x > 1
        \end{cases}$$
        Estudiamos por separado las dos discontinuidades del dato inicial. El primer dato inicial que consideramos es 
        $$u_1(0,x) = \begin{cases}
            0 \quad& x < 0 \\
            1/2 \quad& 0 < x < 1
        \end{cases}$$
        Y aplicando la condición de salto de Rankine-Hugoniot obtenemos que 
        $$\lm = \dfrac{1}{2}(u_1^{+} + u_1^{-}) = \dfrac{1}{4}$$
        Por lo que una primera solución sería 
        $$u_1(t,x) = \begin{cases}
            0 \quad& x < \frac{t}{4} \\
            1/2 \quad& x > \frac{t}{4}
        \end{cases}$$
        Análogamente, el segundo inicial considerado es 
        $$u_2(0,x) = \begin{cases}
            1/2 \quad& 0 < x < 1 \\
            1 \quad& x > 1
        \end{cases}$$
        Y aplicando la condición de salto de Rankine-Hugoniot obtenemos que 
        $$\lm = \dfrac{1}{2}(u_2^{+} + u_2^{-}) = \dfrac{3}{4}$$
        Por lo que una segunda solución sería 
        $$u_2(t,x) = \begin{cases}
            1/2 \quad& x < \frac{3t}{4} + 1 \\
            1 \quad& x > \frac{3t}{4} + 1
        \end{cases}$$
        En conclusión, la solución conjunta sería 
        $$u(t,x) = \begin{cases}
            0 \quad& x < \frac{t}{4} \\
            1/2 \quad& \frac{t}{4} < x < \frac{3t}{4} + 1 \\
            1 \quad& x > \frac{3t}{4} + 1
        \end{cases}$$
        Además, las rectas no se cortan para $t\geq0$, puesto que
        $$\dfrac{t}{4}= 1+\dfrac{3t}{4} \iff t=-2$$
        Por tanto, la expresión a la que hemos llegado es válida para todo $t\geq0$.
    \end{ejercicio}
